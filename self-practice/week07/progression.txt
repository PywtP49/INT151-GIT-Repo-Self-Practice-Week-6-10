============================
📘 DOM PRACTICE PROGRESSION
============================

🎯 หัวข้อ: การฝึกใช้งาน DOM (Document Object Model)
ไฟล์ที่เกี่ยวข้อง: main.js
วัตถุประสงค์: ฝึกใช้งาน DOM เพื่อสร้าง event, เปลี่ยนข้อความ, ซ่อน/แสดงข้อมูล, เพิ่ม element, และใช้เวลา (setTimeout / setInterval)

---------------------------------------------
1️⃣ เปลี่ยนข้อความเมื่อคลิกปุ่ม
---------------------------------------------
สิ่งที่เรียนรู้:
- ใช้ document.getElementById() เพื่อดึง element
- ใช้ addEventListener("click", ...) เพื่อให้ปุ่มตอบสนองเมื่อคลิก
- ใช้ textContent เพื่อเปลี่ยนข้อความใน element

โค้ดทำงานอย่างไร:
เมื่อคลิกปุ่มที่มี id="btnChange" → โปรแกรมจะเปลี่ยนข้อความของ h1 ที่มี id="title" เป็น “Hello DOM!”

แนวคิด:
DOM ทำให้เราสามารถเข้าถึงและแก้ไข HTML ได้แบบ dynamic เช่น เปลี่ยนข้อความโดยไม่ต้องโหลดหน้าใหม่

---------------------------------------------
2️⃣ เพิ่มรายการผลไม้ใหม่เข้าไปใน list
---------------------------------------------
สิ่งที่เรียนรู้:
- การสร้าง element ใหม่ด้วย createElement()
- การเพิ่มเข้าไปใน DOM ด้วย appendChild()

โค้ดทำงานอย่างไร:
เมื่อกดปุ่ม "Add Fruit" → จะสร้าง <li> ขึ้นใหม่ชื่อ “Mango” และเพิ่มต่อท้ายใน <ul> ที่มี id="fruitList"

แนวคิด:
DOM คือโครงสร้างต้นไม้ (Tree) ของ element ทุกตัวใน HTML เราสามารถเพิ่ม/ลบ node ได้ตลอดเวลา

---------------------------------------------
3️⃣ ปุ่มซ่อน/แสดงข้อความ (Toggle)
---------------------------------------------
สิ่งที่เรียนรู้:
- การใช้ style.display เพื่อควบคุมการมองเห็นของ element
- การเขียนเงื่อนไข if-else เพื่อสลับสถานะ

โค้ดทำงานอย่างไร:
เมื่อคลิกปุ่ม “Hide/Show” → ถ้าข้อความถูกซ่อนอยู่จะถูกแสดง, ถ้าแสดงอยู่จะถูกซ่อน

แนวคิด:
style.display = "none" จะซ่อน element โดยไม่ลบออกจาก DOM

---------------------------------------------
4️⃣ นับจำนวนครั้งที่กดปุ่ม
---------------------------------------------
สิ่งที่เรียนรู้:
- การเก็บค่าตัวเลขในตัวแปร
- การอัปเดต textContent ตามค่าที่เปลี่ยน

โค้ดทำงานอย่างไร:
ทุกครั้งที่คลิกปุ่ม “Click Me” → ค่า counter จะเพิ่มขึ้น 1 แล้วอัปเดตข้อความให้แสดง “Clicked: X times”

แนวคิด:
DOM + JavaScript สามารถทำให้เว็บไซต์ตอบสนองต่อการกระทำของผู้ใช้ได้แบบเรียลไทม์

---------------------------------------------
5️⃣ ปุ่มให้ใส่ชื่อ แล้วแสดงคำทักทาย
---------------------------------------------
สิ่งที่เรียนรู้:
- การใช้ prompt() เพื่อรับค่าจากผู้ใช้
- การแสดงผลข้อความใหม่ด้วย textContent

โค้ดทำงานอย่างไร:
เมื่อคลิกปุ่ม “Enter Your Name” → จะมีกล่อง prompt ให้กรอกชื่อ แล้วโปรแกรมจะแสดงข้อความทักทาย “Hello, ชื่อ!”

แนวคิด:
เราสามารถรับ input จากผู้ใช้ได้โดยตรง และแสดงผลกลับทันทีโดยไม่ต้องรีเฟรชหน้า

---------------------------------------------
6️⃣ Pop Cat Clicker (ภาพเปลี่ยน + นับแต้ม)
---------------------------------------------
สิ่งที่เรียนรู้:
- การเปลี่ยน attribute ของ element เช่น src ของ <img>
- การใช้ setTimeout() เพื่อหน่วงเวลา

โค้ดทำงานอย่างไร:
เมื่อคลิกภาพแมว → คะแนนจะเพิ่ม +1  
ภาพจะเปลี่ยนเป็นแมวอ้าปาก แล้วกลับมาปิดปากหลัง 0.3 วินาที

แนวคิด:
setTimeout() เหมาะกับการทำ action แบบชั่วคราว เช่น แอนิเมชัน หรือการดีเลย์บางอย่าง

---------------------------------------------
7️⃣ ตัวอย่างการใช้ setInterval() (เปลี่ยนสีพื้นหลัง)
---------------------------------------------
สิ่งที่เรียนรู้:
- การใช้ setInterval() เพื่อทำซ้ำโค้ดในช่วงเวลาที่กำหนด

โค้ดทำงานอย่างไร:
ทุก ๆ 1 วินาที (1000 มิลลิวินาที) → พื้นหลังของหน้าเว็บจะเปลี่ยนสีวนไปตามลำดับ

แนวคิด:
setInterval() ใช้ในงานที่ต้องการการเปลี่ยนแปลงต่อเนื่อง เช่น นาฬิกา, counter, หรือ animation loop

---------------------------------------------
💡 สรุปสิ่งที่ได้จากการฝึก DOM
---------------------------------------------
1. document.getElementById()
   → ใช้เลือก element จาก HTML โดยอิงจาก id
   
2. addEventListener("click", function)
   → ใช้สร้าง event เมื่อผู้ใช้คลิกปุ่ม

3. textContent
   → ใช้เปลี่ยนข้อความใน element

4. style.display
   → ใช้ซ่อนหรือแสดง element

5. createElement() / appendChild()
   → ใช้สร้าง element ใหม่และเพิ่มเข้า DOM

6. setTimeout()
   → ใช้หน่วงเวลาให้โค้ดทำงานหลังเวลาผ่านไป

7. setInterval()
   → ใช้ให้โค้ดทำงานซ้ำในทุก ๆ ช่วงเวลาที่กำหนด

---------------------------------------------
🧭 แนวทางการฝึกต่อ (Guide Line)
---------------------------------------------
✅ ลองสร้างปุ่มใหม่ เช่น “Change Background”, “Add Random Color”
✅ ลองใช้ input แทน prompt เพื่อรับค่าจากผู้ใช้
✅ ลองใช้ classList.toggle() แทนการเปลี่ยน style.display
✅ ลองสร้างเกมง่าย ๆ โดยใช้ setInterval() และ setTimeout()
✅ ลองใช้ querySelector() / querySelectorAll() เพื่อฝึกเลือก element หลายตัว

---------------------------------------------
🔥 สรุปสุดท้าย
---------------------------------------------
DOM (Document Object Model) คือ “สะพานเชื่อม” ระหว่าง HTML กับ JavaScript  
มันทำให้เราสามารถ:
- อ่าน/เขียน/แก้ไขโครงสร้างของหน้าเว็บได้
- เพิ่มลูกเล่นแบบโต้ตอบ (Interactive)
- สร้างเว็บที่มีพฤติกรรมตอบสนองแบบ Dynamic
