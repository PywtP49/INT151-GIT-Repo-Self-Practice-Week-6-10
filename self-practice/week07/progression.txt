---------------------------------------------
1. เปลี่ยนข้อความเมื่อคลิกปุ่ม
---------------------------------------------
ตอนเริ่มจะมีข้อความ Welcome! อยู่ใน h1  
เมื่อกดปุ่มที่กำหนดไว้ ข้อความจะเปลี่ยนเป็น “Hello DOM!”  

สิ่งที่ได้เรียนรู้คือการใช้ document.getElementById() เพื่อเข้าถึง element  
และใช้ addEventListener("click", ...) เพื่อให้ปุ่มทำงานเมื่อถูกคลิก  
ส่วนการเปลี่ยนข้อความใช้ textContent  

สรุปสั้น ๆ คือ DOM ช่วยให้เราเปลี่ยนเนื้อหาในหน้าเว็บได้โดยไม่ต้องโหลดใหม่

---------------------------------------------
2. เพิ่มรายการผลไม้ใน List
---------------------------------------------
เมื่อคลิกปุ่ม “Add Fruit” โปรแกรมจะสร้าง <li> ใหม่ชื่อ “Mango”  
แล้วเอาไปต่อท้ายใน <ul id="fruitList">  

อันนี้ได้ฝึกใช้ createElement() เพื่อสร้าง element ใหม่  
แล้วใช้ appendChild() เพื่อเพิ่มเข้ากับ DOM  

แนวคิดหลักคือ HTML ทั้งหน้าเว็บเป็นเหมือนโครงสร้างต้นไม้  
เราสามารถเพิ่มหรือลบ node ได้ตลอดเวลา

---------------------------------------------
3. ปุ่มซ่อน/แสดงข้อความ
---------------------------------------------
เมื่อคลิกปุ่ม “Hide/Show” จะสลับการแสดงผลของข้อความ  
ถ้าตอนนั้นข้อความมองเห็นอยู่ ก็จะถูกซ่อน  
แต่ถ้าถูกซ่อนอยู่ก็จะกลับมาแสดงอีกครั้ง  

ใช้ style.display เพื่อควบคุมการมองเห็น  
เช่นถ้า display = "none" จะซ่อน element แต่ไม่ได้ลบมันออกจริง ๆ  

---------------------------------------------
4. นับจำนวนครั้งที่คลิก
---------------------------------------------
ทุกครั้งที่กดปุ่ม “Click Me” ตัวเลขจะเพิ่มขึ้นทีละ 1  
แล้วข้อความในหน้าจะอัปเดตเป็น “Clicked: X times”  

ได้ฝึกเรื่องตัวแปร การเก็บค่า และอัปเดตข้อความใน DOM  

ตรงนี้ทำให้เห็นว่า JavaScript สามารถทำให้หน้าเว็บตอบสนองแบบเรียลไทม์ได้

---------------------------------------------
5. ปุ่มใส่ชื่อแล้วแสดงคำทักทาย
---------------------------------------------
เมื่อกดปุ่ม “Enter Your Name” จะมีกล่อง prompt ขึ้นมาให้กรอกชื่อ  
หลังจากพิมพ์ชื่อเสร็จ โปรแกรมจะแสดงข้อความว่า “Hello, ชื่อของคุณ!”  

ฝึกการรับค่าจากผู้ใช้ด้วย prompt()  
แล้วใช้ textContent เพื่อแสดงข้อความตอบกลับทันที  

---------------------------------------------
6. Pop Cat Clicker (ภาพเปลี่ยน + นับแต้ม)
---------------------------------------------
อันนี้สนุกหน่อย คลิกที่ภาพแมวแล้วจะได้คะแนนเพิ่ม  
พร้อมกับภาพเปลี่ยนเป็นแมวอ้าปาก แล้วกลับมาเป็นปิดปากหลัง 0.3 วินาที  

ได้ฝึกใช้ setTimeout() เพื่อหน่วงเวลา  
และฝึกเปลี่ยน attribute ของ element เช่น src ของ <img>  

---------------------------------------------
7. เปลี่ยนสีพื้นหลังอัตโนมัติ
---------------------------------------------
โปรแกรมนี้ใช้ setInterval() เพื่อให้โค้ดทำงานซ้ำทุก ๆ 1 วินาที  
โดยจะเปลี่ยนสีพื้นหลังของหน้าเว็บไปเรื่อย ๆ  

เป็นตัวอย่างที่ดีของการใช้ setInterval() กับงานที่ต้องอัปเดตตลอดเวลา  
เช่น นาฬิกา เคาน์เตอร์ หรือ animation loop  

---------------------------------------------
สรุปสิ่งที่ได้เรียนรู้
---------------------------------------------
- document.getElementById() → ใช้เลือก element  
- addEventListener() → ทำให้ปุ่มหรือ element มีการตอบสนอง  
- textContent → เปลี่ยนข้อความในหน้าเว็บ  
- style.display → ซ่อนหรือแสดง element  
- createElement() / appendChild() → สร้างและเพิ่ม element ใหม่  
- setTimeout() → หน่วงเวลาให้โค้ดทำงานทีหลัง  
- setInterval() → ให้โค้ดทำงานซ้ำตามเวลาที่กำหนด  

---------------------------------------------
แนวทางฝึกต่อ
---------------------------------------------
- ลองเพิ่มปุ่มเปลี่ยนสีพื้นหลังแบบสุ่ม  
- ใช้ input แทน prompt เพื่อรับค่าจากผู้ใช้  
- ใช้ classList.toggle() แทน style.display เพื่อสลับการซ่อน/แสดง  
- ลองทำเกมเล็ก ๆ ที่ใช้ setInterval() และ setTimeout()  
- ฝึกใช้ querySelector() / querySelectorAll() เพื่อเลือก element หลายตัวในครั้งเดียว  

---------------------------------------------
สรุปสุดท้าย
---------------------------------------------
DOM คือส่วนสำคัญที่เชื่อมระหว่าง HTML กับ JavaScript  
ทำให้เราควบคุมทุกอย่างในหน้าเว็บได้ เช่น ข้อความ, สี, รูปภาพ, หรือการตอบสนองต่อผู้ใช้  
พอเข้าใจ DOM แล้ว จะสามารถสร้างเว็บที่โต้ตอบและดูมีชีวิตชีวามากขึ้นได้จริง ๆ
